# Actividad 1: Tarjeta de Presentación en React (Intro a React)

## 📌 Descripción del Proyecto
Este proyecto corresponde a la **Actividad 1 del Módulo 4: Intro a React**. Su objetivo fundamental es comprender la arquitectura declarativa de React, el funcionamiento del Virtual DOM y la sintaxis JSX a través de la construcción de componentes funcionales reutilizables y modulares.

---

## 🎯 Objetivos de Aprendizaje y Conceptos de Lecturas Cumplidos
- **Creación de proyectos con Vite:** Configuración de un entorno ágil con Hot Module Replacement (HMR).
- **Componentes Funcionales:** Definición de bloques de construcción modulares en React.
- **Sintaxis JSX:** Incrustación de expresiones JavaScript dinámicas mediante llaves `{}` y atributos estándar como `className`.
- **Props (Properties):** Paso unidireccional de datos del componente padre (`App.jsx`) al componente hijo (`Tarjeta.jsx`).
- **Interactividad con useState:** Incorporación de estado local reactivo para likes y alternador de contacto.

---

## 📋 Lo que debe llevar / Requisitos Cumplidos
1. **Proyecto React con Vite:** Configurado y funcionando en el puerto 5173.
2. **Componente `Tarjeta.jsx`:** Modularizado, estilizado y capaz de renderizar información estática y dinámica.
3. **Reutilización:** Múltiples tarjetas renderizadas a partir de un arreglo de objetos perfiles.
4. **Interactividad:** Botón de "Me Gusta" con contador incremental y botón para desplegar correo de contacto.
5. **Estilos profesionales:** Diseño tipo tarjeta oscura con sombras, badges y efectos hover.
